# Big Data Analytics — Online Shop

A Python-based business analytics system for analyzing online shop
sales, customer behavior, product performance, and customer sentiment.

## Project Overview

The application will generate and process synthetic e-commerce data,
perform statistical analysis, forecast sales, segment customers,
analyze customer reviews, and present business insights through
an interactive dashboard.

## Technology Stack

- Python
- Pandas and NumPy
- SciPy
- Scikit-learn
- TensorFlow / Keras
- Matplotlib and Seaborn
- Plotly
- Streamlit
